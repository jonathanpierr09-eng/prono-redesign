# PRONO — Analyse football

Interface d'analyse statistique des rencontres : calendrier, résultats, forme récente et estimations de scores. Thème dark lumineux et bordeaux.

## Déploiement Vercel
- Framework : Other
- Build command : aucune
- Output directory : `./`
- Fonctions serverless : `api/`

## Données
- ESPN : calendrier, résultats et historiques publics.
- Sofascore : données handball lorsque disponibles.

Les estimations sont indicatives et ne constituent pas des garanties de résultat. Cette version présente des statistiques sportives, sans service de paris.
